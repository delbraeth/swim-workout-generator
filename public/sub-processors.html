Sub-processors

Last updated: 2026-05-26

SetForge uses a small set of third-party services to operate the application. This page lists every vendor that touches user data, what data they see, and where it's stored. We update this page when sub-processors change.

For organizations evaluating SetForge: if you need this list in a different format (PDF, CSV, vendor-specific questionnaire), email hello@setforge.io.

What we don't use

For symmetry with the sub-processor list, the things SetForge explicitly does not integrate with:

  • No analytics — no Google Analytics, no Mixpanel, no Amplitude, no Plausible, no Fathom, no anything
  • No ad pixels or trackers — no Facebook Pixel, no LinkedIn Insight, no Twitter pixel
  • No A/B testing infrastructure — no LaunchDarkly, no Optimizely, no Statsig
  • No session replay — no FullStory, no Hotjar, no LogRocket
  • No third-party customer support — no Intercom, no Zendesk, no Drift
  • No third-party CRM — no HubSpot, no Salesforce

How we notify of changes

When we add, remove, or change a sub-processor:

  • This page is updated with the change and the date
  • The change is announced in the SetForge changelog
  • For changes that materially affect user data handling, active users receive an email notification (when outbound email is live; see "Planned" table above)
