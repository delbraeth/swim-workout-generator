# SetForge — Solo Athlete Live Intro

**Format:** Live Zoom session, 30–45 min, 5–15 solo swimmers.
**Facilitator:** Cap'n, a community manager, or any swimmer comfortable doing live demos.
**Outcome:** Every attendee generates their first workout during the session and leaves knowing how to log it after they swim.

---

## Pre-call checklist (1 page)

### 24 hours before the session

- [ ] **Confirm attendee count.** Cap soft at 15. Above that, run two sessions.
- [ ] **Send attendees the workbook PDF** (`workbook.md` exported as PDF) with the calendar invite. Ask them to skim pages 1–2 (Before You Start + Anatomy of a Workout).
- [ ] **Verify everyone has a SetForge account.** Invite-only — confirm in your invite admin panel that every attendee has redeemed their invite or has one queued. Anyone without an account before the call can't follow the demo.
- [ ] **Ask attendees to know their per-100 pace** (or commit to using Swimmer Level for now). One sentence in the reminder email: *"Bring a 100-yard time you can comfortably hold for 10×100. Don't know it? No problem — we'll use a starting estimate."*

### 30 minutes before the session

- [ ] **Open SetForge** in a fresh browser window. Sign in with a demo account (or your own — your live history is fine if you're not self-conscious about it).
- [ ] **Set your pool mode** to SCY (default) for the demo. If most attendees are meters swimmers, switch and call it out.
- [ ] **Clear your Focus note** if one was set from a prior session — you want a clean generate.
- [ ] **Open the workbook in a second tab** so you can flip to a reference page if a question lands there.
- [ ] **Open the user manual** (`/manual.html`) in a third tab as your backup truth source for any edge-case question.
- [ ] **Disable system notifications.** Slack and email banners during a screen share are noise.
- [ ] **Open Zoom chat** in a side panel — questions will flow there during demos.

### Have open on screen at start

- SetForge generator page (signed in, freshly loaded)
- Zoom chat
- A simple slide deck (10–14 slides — see Run of Show below)

### Recording

Default to recording the session unless an attendee opts out. Post the recording in your community channel after — attendees who couldn't make it benefit, and you build a library of reference sessions.

## Demo scripts (3)

### Demo 1 — Pace input setup

> **Setup:** generator page open, pace field empty or showing a default.

**Facilitator says:** "First thing we set — and the one thing we set today — is your per-100 pace. This is the time you can comfortably hold for 100 yards over a longer set. Not your fastest 100. Honest cruise. Mine is around two minutes flat, so I'll type **2:00**."

[Type `2:00` in the pace field. Wait 2 seconds.]

"Notice the field doesn't have a Save button. SetForge saves it about 1.5 seconds after I stop typing — you'll see no visual confirmation, that's intentional, the field just remembers. Now my pace is set for every future workout until I change it."

[Hover the ~60 min / ~90 min / ~2hr preset buttons.]

"Watch these presets. They didn't have values before — now they show real distances based on my pace. About 2,800 yards for an hour at my speed. If I bump my pace to 1:40 — " [type `1:40`, wait] " — the same hour now shows 3,400 yards. Faster swimmer, more yards in the same time."

[Pause for chat questions: "What if I don't know my pace?"]

"Two ways. One, swim a 200 next time you're at the pool, divide by 2 — that's the test set on workbook page 1. Two, open Profile, tap Swimmer Level, pick Recreational, Masters, or Competitive — that sets a starting pace. Refine later."

### Demo 2 — Generate for time

> **Setup:** pace set, no workout generated yet.

**Facilitator says:** "Let's generate something. I want about an hour, technique-focused, because today's a recovery day for me."

[Tap the **~60 min** preset. Slider moves to ~2,800.]

"~60 min preset pulled the slider to 2,800 yards based on my pace. I'll go with that."

[Tap the **🎯 Technique** card.]

"Technique workout — drill-heavy, lower intensity. No equipment today — I'll leave all the equipment cards off. And I want a focus note — let's say…"

[Click the Focus field. Type **"long underwater pulls"**.]

"This focus note stays with the workout. Shows up in Run Mode between sets, prints at the top of the page, sticks to my history entry. Don't overthink it — anything you want to remember."

[Tap the big **🏊 Generate Workout** button.]

"Four blocks. Warm-Up, Drill, Main, Cool-Down. Total yardage up top — let me check what I got — 2,650 yards, ~68 minutes including rest. Each block has its own color. Drill is teal, main is blue, that's how I scan it on deck."

[Scroll through the blocks slowly. Pause on the effort-zone pill in the Main header.]

"See this little pill in the main block? Mine says Aerobic in blue — that's the dominant intensity. Tells me at a glance this is a sustainable workout, not a sprint day."

### Demo 3 — Regenerate a section

> **Setup:** workout from Demo 2 still on screen.

**Facilitator says:** "Say I don't love the drill. I've done catch-up drill three workouts in a row, I want something different."

[Hover the **↺** button on the Drill block.]

"Each block has this little arrow-circle in the header. Tap it to regenerate just that block. The warm-up, main, and cool-down stay exactly as they are — only the drill changes."

[Tap the **↺** button. New drill renders.]

"Different drill. Different intervals. The rest of the workout untouched. If I still don't like it — tap again."

[Tap **↺** once more for emphasis. Don't overdo it — usually one regen is the point.]

"Two things to call out. One, regenerating a section marks the whole workout unsaved if you'd already saved it — you'll be re-prompted before printing. Two, the generator avoids giving you the same set immediately, so each regen really is a different option, not a coin flip."

[Briefly hover the ⇄ button on a single set inside the Main block.]

"And inside any block, the ⇄ arrows on a single set offer a shorter or longer version. Useful when you like the workout shape but one set is too much or too little. Doesn't change the other sets in the block."

## Discussion prompts (5)

Run any 2–3 of these depending on the room. Each is meant to draw out real questions, not lecture.

1. **"What's your typical week look like right now? Three swims? Five?"** *(3 min)* — Helps you tune the workbook starter rotation to what they actually do.
2. **"Show of hands — who knows their per-100 pace within 5 seconds?"** *(2 min)* — Reveals how many will need the Test Set. Adjust your follow-up email accordingly.
3. **"What's one thing you wish your last coach gave you that they didn't?"** *(4 min)* — Surfaces what SetForge can help with vs what it can't. Set expectations honestly.
4. **"Anyone here ever logged a workout in another app and then never opened the app again?"** *(3 min)* — Get them talking about logging friction. Sets up why SetForge's one-tap log matters.
5. **"What's your biggest fear about a generated workout?"** *(3 min)* — Usually surfaces "what if it's wrong for me?" — answer: regenerate the section, swap the set, edit the interval, every escape hatch is there.

## 10-Question FAQ

**Q1. Do I need a coach to use this?**
No. It's built for self-coached swimmers. If you have a coach, SetForge can supplement (generate the second swim of the week your coach didn't write) but doesn't replace one.

**Q2. What pool sizes are supported?**
25 yards (SCY), 25 meters (SCM), and 50 meters (LCM). Switch with the toggle above the workout-type cards. Each mode has its own slider range and pace unit.

**Q3. Do I need to enter my pace every time?**
No. Set it once in the pace field — it saves automatically to your account and follows you across devices.

**Q4. What if the workout is too hard or too easy?**
Adjust your per-100 pace input. Rescale all intervals proportionally. Or edit a single interval inline. Or hit Recovery Mode for a one-off easy day. Or pick a less intense workout type. Lots of levers.

**Q5. Can I do the same workout twice in a row?**
Yes — open it in History and tap the 🔁 Repeat button. Loads it back into the generator as an unsaved workout you can re-run. Otherwise the generator down-weights anything you've done in the last 7 days, so the same main rarely repeats by accident.

**Q6. Does it work offline?**
The web app needs a connection to load and to save. Once a workout is on screen, Run Mode runs locally — you can be in airplane mode for the swim itself. Save when you're back on wifi.

**Q7. Where's my data stored? Who can see it?**
Your workouts, settings, and favorites live in SetForge's database. Only you see your own data — there's no public profile, no sharing, no leaderboard. Privacy details are in `/privacy.html`.

**Q8. Can I share a workout with a friend?**
Yes — fastest way is **📋 Copy Text** in the summary bar. Pastes a clean human-readable version into Messages, Notes, anywhere. Or print to PDF and send the file.

**Q9. What if I find a bug?**
👤 Profile → 💬 Send feedback. Pick 🐛 Bug, type what happened, hit Send. Your page URL and browser info attach automatically.

**Q10. Is there a paid tier?**
Solo athletes are free, forever. No upsell. Coach and program tiers exist for people running teams, but that's outside what you'll use as a solo swimmer.

## Facilitator self-debrief (after the session)

Spend 5 minutes immediately after the call writing down:

1. Which slide ran long or short? Adjust the run-of-show for next time.
2. What question came up that wasn't in the FAQ? Add it.
3. Did any attendee bounce off something specific in the app? Flag it for Cap'n via feedback or DM.
4. How many attendees actually generated a workout during the session? Target: 100%. Below 80% and demo 2 needs tightening.

Treat each session as a tuning pass on this guide. Update the guide in place.
